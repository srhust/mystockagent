# 周期股量化交易系统 — 温度引擎 + V4三锚体系

聚焦周期板块轮动的量化系统。核心理念：**周期走的是整个板块而非个股**（存储、猪、航运、有色、煤炭），
以行业温度 0-100 驱动"深寒买入、过热卖出"；V4 加入相对回撤锚与商品位置锚，个股/美股同构泛化。

## 三锚体系（V4）

| 锚 | 定义 | 作用 |
|---|---|---|
| ①相对回撤锚 | 距自身高点回撤 ≥ 自身振幅（自适应阈值 0.7×历史最深回撤，下限30%） | 成长型周期股的周期底（股价位置锚对其失效，实证：牧原温度12年0信号） |
| ②商品位置锚 | 对应商品在自身5年区间 <60% | 排除商品高位的假深寒（事件级 +15pp 分离） |
| ③温度/广度锚 | temp<12 触发 | 扣扳机时点（股价领先商品反转，实证中位领先31%，82%事件商品已反弹>10%） |

仓位管理：**30/35/35 三档摊平**（入场30，-15%加35，-30%加35），出场 85（非金融）/75（金融）。
资金模式：每资产独立账户、贪心建仓、多资产并行，最大化资金在投率。

## 已验证数字（2010-2026，16.8 年）

**净值口径 V4.1（修正账本：T+1 收盘成交、双边费 0.15%、缺价受控估值、T-1 决策时间戳；边界测试 6/6 通过）**：

| 消融 | 配置 | 净值 CAGR | MDD |
|---|---|---|---|
| A | 仅温度 12/75 | +9.58% | -27.6% |
| **B** | **温度+相对回撤锚** | **+10.81%** | **-36.7%** |
| C | B+商品过滤 v2 | +10.83% | -39.0% |
| D | C+三档摊平 | +6.71% | -31.1% |
| E | D+仅顶部退出 | +4.99% | -38.3% |

组件贡献（净值口径）：回撤锚 +1.2pp；商品过滤 ≈0；三档摊平 -4.1pp（组合层资金闲置代价，专户口径另计）；dd 修复出场 +1.7pp。Regime 层（指数<MA200 减仓）已测被拒——与深寒逆势建仓结构性不相容。注意：早期报告的 -82.3%/-65.0% MDD 大部分是缺价估值伪影，修正后真实 MDD 为 -27.6%/-36.7%。

**事件级（研究口径，非真实组合收益）**：

| 策略 | 数字 | 备注 |
|---|---|---|
| 组合底盘 | +12.0% 理论 / OOS +9.8% | 695 深寒事件，胜 92% |
| 专户三档摊平 | +31% 在投 | 109 笔，资源+58%/科技+65%/农业+61%/金融+22% |

已知损耗：行业指数理论回测 15.3% → ETF 可交易载体 8.2%（2021-2026 同窗口，仅 9/26 映射达标）——真实收益以载体口径为准。

关键实证：底部相对性（牧原 -50% 只在 2023 代际底触发，振幅自适应是正解）；
商品高位深寒是假信号（+19% 组）；85 出场在贪心模式劣于快速修复出场（资金闲置成本）。

## 使用

```powershell
python main.py --no-fetch            # 刷新信号
python scripts/daily_advisor.py      # 每日决策 → output/daily_advice.md
python scripts/v4_v21.py             # V4 回测
```

## 结构

- `strategy.py` 温度引擎（含 cold_v2 期货背离模式）｜`config.py` 参数与映射
- `scripts/` 全部研究/回测/审计脚本 ｜ `output/` 报告 ｜ `data/` 行情缓存（不入库）
- 数据源：THS 行业指数、新浪期货/美股、baostock 个股 qfq（单锚点全历史，30/30 行业 + 12/12 期货跨源核对一致）
