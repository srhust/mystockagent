# 周期股量化交易系统 — CycleTrend-v1

覆盖周期反转、启动突破、趋势延续、顶部衰退和资金配置的完整周期交易研究系统。
前身：温度引擎 + V4三锚体系（保留为 Baseline）。

## 核心结论（2026-10-13 冻结，全部有同口径实验支撑）

| 问题 | 结论 | 证据 |
|---|---|---|
| 唯一被证实的正增量 | **30/35/35 防御性分批**：单位暴露收益 +50%（97.6% vs 同暴露一次性 65.3%），Sharpe 0.81 | MU 暴露匹配实验（Phase 3） |
| MU 最优配置 | V4 入场 + 突破顺势加仓（add_frac=0.35）：**+10.48%/Sharpe 0.83/MDD -20.6%**，10 次 ADD，逐轮资金用满；逆势 30/35/35 为资本效率对照（+10.38%/0.81/-29.7%，账户贡献合计 425pp vs E 433pp） | A-G 消融+hybrid 复验（审查七~十轮） |
| A 股 ETF 最优配置 | Baseline 六槽一次性：**+5.96%/Sharpe 0.50/MDD -21.4%**（9 只高保真载体，0.1%/边） | ETF 全链路消融 |
| 突破引擎 | **负结果**：裸 Donchian 状态信号 141 次往返绞杀收益；经状态机去重仍捕获中位 0% | Phase 2 |
| 顺势加仓 | **修订（审查七~十轮）**：加仓门 bug 修复后突破顺势加仓 10 次 ADD 真实成交；账户贡献口径下 E（433pp）≈A（425pp）但 MDD 浅 9pp——突破作入场通道无效、作持仓加仓通道有效；组合无增益 | engine hybrid + mu_per_cycle_final |
| 产业因子 | **负结果+缺失**：DRAM/NAND 免费源不存在；SOX-RS 门控对左侧入场是结构性反作用（MDD -47.7%） | Phase 4 |
| 动态资金分配 | **负结果**：score 加权无收益增量（5.89% vs 5.96%），MDD 恶化，仅恢复更快 | Phase 5 |
| 30 行业漏检诊断 | 49 轮漏检中 42 轮是浅周期（-30%~-40%）；但浅回撤路径的补充入场未通过组合收益验证 | cycle_labels 诊断 |
| 严格滚动 OOS | LR 排序逐折 AUC 0.45-0.80 不稳定；CS+ranker ETF 收益从 5.00%（混入训练分）降至 3.25% | CycleStart-v1 遗产 |

**设计教训**：多路径候选/产业因子/动态分配均未战胜"深寒集中入场 + 防御分批 + 温度出场"。真正的优势来源是入场的极端选择性（17 年 5 次）与分批的风险结构。

## 系统架构

```
cycle_system/
    engine.py               # 唯一交易账本: run_ledger(共享池)/run_specialist(专户/动态预算)
                            #   T+1执行/缺价禁成交/加仓T-1确认T执行/费用入账/暴露度输出
    cycle_labels.py         # 周期标签: 谷底(冻结30%)/zigzag周期/triple-barrier有效启动
    reversal_detector.py    # Engine A 左侧: temp_v4 + 自适应回撤, first-touch标签
    breakout_detector.py    # Engine B 突破: Donchian穿越+回撤前提+失败检测
    cycle_state_machine.py  # 统一状态机: unified(FLAT门控/一轮一cycle_id/防重冷却)
    capital_allocator.py    # 动态资金分配(机会评分+集中度上限+观察预留)
    carriers.py             # A股9只高保真ETF载体(corr≥0.85)
    anchors.py              # 底部/顶部模型拆分
paper/paper_trade.py        # 模拟盘v1.2: ETF真实价/T+1挂单/新鲜度门禁/真实时间戳/账户持久化
tests/test_engine.py        # 7项生产引擎直测(缺价/恒等式/预算封闭/时序/费用)
```

## Cycle Bottom Nowcaster（研究轨→生产轨，审查十二~十三轮）

- **生产候选 = 规则版**（`scripts/nowcaster_v9_rule.py`）：`dd252 ≤ -35% 且 pos1250 ≤ 35%` 即预警。零训练、零泄漏、可解释。MU 召回 5/9（提前中位 -127 日、假警 0.3/年）、WDC 7/8、INTC/AMAT ~50%；适用域=周期股深跌型底部（LRCX/TXN/ASML/KLAC 成长股底部不触发，属预期外行为）。
- **ML 版演进**（v0→v8）：单股→池化→质量谷底标签（谷后120日涨幅≥50%）→SEC免费产业特征（营收/毛利，available_at=提交日）→组内留一自交叉（LOOX 诚实口径）。迁移解构：可跨股票的技能="跌得深+位置低"签名（dd252 系数 -1.7~-3.4 绝对主导），产业特征系数≈0。
- **产业数据定位（两轮双定义证伪）**：价格预警时营收仍在恶化（加速/未创新低两定义均 0 触发）——产业证据为**确认性**（加仓/持有信心），非触发性（季报 available_at 滞后 30-60 日，快 V 底不可见）。
- **接入 V4 实验**（`scripts/mu_rule_gate_test.py`，2009-2026 全周期统一台账）：V4 基线终值 523.89/15 笔/MDD -29.7% → **V4+规则状态过滤 528.18/11 笔/MDD -19.4%**——收益微增、回撤减 10.3pp、交易少 4 笔。Nowcaster 价值定位=风险过滤，非收益增强。
- **前向记录**：`scripts/nowcaster_daily.py` 每次运行输出 11 股当日状态至 `data/nowcaster_daily/`（当前预警中：无）。
- 诚实边界：浅回撤启动周期（MU 2010-2012 型）不可召回；阈值选自 v8 系数分析（轻度样本内，未按股调参）；QCOM↔INTC 迁移 4/6 为最强跨股证据。

## ⚠️ 审查十四轮更正(严格事件评价, scripts/nowcaster_eval_strict.py)

上表的宽窗口径(250日命中窗+±10日假警窗+段首回填)存在时间偏差, 严格口径(连续5日确认日为预警时点, 一对一匹配, 20/60日期限)下的真相:

- **规则版识别的是"深跌区域", 不是"底部将至"**: MU P@20=0.00 P@60=0.00, R@60=0.11, **预警后60日继续下跌中位 -26.8%**; WDC 续跌-22.0%; STX P@60=0.50(续跌+6.2%)与AMAT P@60=0.48(+1.6%)有弱信号; TER P=1.00(仅2事件)。
- **V4门控改善回撤的机制因此自洽**: 规则状态标记的是"高继续下跌风险区", 持仓过滤砍掉的正是落刀段 — 它是风险过滤器, 不是底部预测器, 两件事不再混淆。
- **"在日期T判断20/60日内将见底"的问题仍未解决**。此为最高优先级研究目标, 评价以 nowcaster_eval_strict.py 的严格口径为准。
- 已知待修: rev_yoy 在日频序列上 shift(4)(应为季度序列先算同比再as-of对齐); ML 测试期 P98 阈值应改为训练期冻结; ML 的 days_since_prev_trough 应改用 zigzag 确认日(反弹30%时点)而非谷底日。在修复并重评之前, "产业因子无增量"的结论不成立(撤回)。

## 审查十四轮补: "MU两年一周期很明显, 为什么系统捕捉不到"——逐谷诊断结论

- 合格谷底集(9谷/17年)与肉眼两年周期一致, 标签无错。
- **dd252深跌条件可覆盖7/9谷**(2018-12深-56%、2020-03深-44%、2025-04深-58%)——系统看得到周期区域。
- **元凶是pos1250(5年低位)条件**: 周期底绝对价逐轮抬升(3→7→27→32→64→322), 5年分位不再低, 2018/2020两轮被它误杀。dd252单条件召回升至4/9(P@60=2/21, 续跌-16.9%)。
- 本质难点由此清晰: **区域可见、时点不可见**——深跌可测, "区域内何时见底"不可测(谷深逐轮不同: -79%~-30%无稳态)。解法=两阶段: 深跌区进入(阶段1)后等趋势结构确认(阶段2), 放弃预测最低点。

## 审查十五轮终稿: 两份报告与体系结论

### Fast-V Report(急跌反弹交易系统 v1.0, 冻结规格)
- 规格: 急跌=dd252十日降≥15pp(90日去重, 15日有效期) | 入场=首次收复MA10(≥2日)∧SEC营收同比as-of>-30% | 出场=TP+15%/3σ20止损/限时60日, T+1
- 消融依据: F0分布(MA5收复中位3日100%≤10日, h20中位MU+4.2%/STX待重验/WDC+1.2%) → E2入场(MA10, 三股合计461 vs E0 376/E1 283/E3 383) → X1出场(跨股稳健)
- 结果: MU 169.30/-21.0% | WDC 162.2/-22% | STX作废(数据源污染待重验)
- 定性: 急跌反弹优势真实(三股h20胜率55-60%); 入场是杠杆(E1→E2翻倍), 出场不是; 财报as-of过滤在快V有效(挡基本面崩塌型假反弹)

### CycleTrend Report(周期发现与捕获)
- 双路径: A深跌复合确认(dd≤-40%+MA20收复上行+未脱MA50) 6/9谷, P=6/12 | B浅回撤重启(MA50上拐+回撤10-30%) 5/9, P=5/21 | 联合8/9(唯一漏网2020-03快V归Fast-V)
- 账户级: 事件持120日=462.68/-61.8% (事件是探测器非持仓保险) | V4+阶段1过滤528.18/-19.4%仍为账户级最优
- P2退出: V4状态机退出全面优于MA50/MA100/跟踪/棘轮(528.18 vs 445/325/378/494) — 价格水平类退出无增量
- P3: 同标的卫星拆分证伪(相关性≈1分散是幻觉); 跨标的评分须引擎口径(日收益近似失真40倍作废)

### 体系结论(本轮沉淀)
1. 区域可见/时点不可见 → 复合拐点规则P=50%达标, 滞后17日为精度的价格
2. 三引擎分工: V4核心(入场+持仓) / 双路径发现(8/9) / Fast-V独立事件流 — 角色不可互替
3. SEC产业数据=确认层非触发层(拐点过滤负结果入档)
4. 严格验证纪律的实战价值: 抓获STX数据源污染(-643%毒日), 避免污染全部下游结论
5. 待办: STX换源重验(yfinance/stooq环境受阻) → 跨标的引擎口径比较 → 分配器
