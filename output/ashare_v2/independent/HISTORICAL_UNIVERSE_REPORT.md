## 1. 方法与裁定符合性

| 裁定 A1 要求 | 实现 |

| 不得以年末存续作当年全集 | **区间语义**：存续 ⇔ ipoDate ≤ Y-12-31 ∧ (在市 ∨ outDate ≥ Y-01-01) |
| 年内新上/年内退市/年初已上 | `new_listed`（ipo∈Y）/`delisted_in_year`（out∈Y）/`alive_end_year` 分列 |

## 4. 限制声明（诚实边界）
1. **代码变更**：`query_stock_basic` 按代码单值返回，A 股历史上代码变更（如 600xxx 转板）在官方源不可见——若存在此类券，其新旧代码各自成条；本层不猜测合并。
2. **outDate=最后交易日**已由 K 线互证，但**退市生效公告日**（晚于最后交易日数周~数月）无字段；处置期（退市整理板）bar 若存在则以实测 bar 为准。
3. B 股（type=2/3 类）不在 type=1 股票口径内；指数/ETF 排除。
4. 1990-1997 上市券 ipoDate 完整（9014 全集含之前年份），存续判定覆盖 1998 起点无碍。
