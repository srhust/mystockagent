# RAW 交易域归因报告 — 阶段1/2 主交付（2026-10-19，基线 578418e）

> 裁定遵从：本报告**不作性能判断**（不称"盈利/亏损能力"结论），只做**收益差来源分解**。
> 全部 REPLAY：250 票幸存者池、PIT 冻结快照、非前向非 OOS。
> 引擎/预测规则零改动：RAW 域由 `tools/raw_shadow_runner.py`（Runner 子类）实现，16 预测模块哈希未变。

## 1. 81 日窗（2026-03-02 → 2026-06-30）新旧对照

| 读数 | NAV末 | 相对20000 | 账本性质 |
|---|---|---|---|
| 旧 SHADOW（close_adj 成交+adj 估值） | 17,233.92 | **-13.83%** | **污染账本**（151行/81唯一hash，见 forensics） |
| 新 RAW（T+1 raw open 成交/raw close 估值） | 15,814.89 | **-20.93%** | 隔离新账本，selfcheck 四关全绿 |

**分解（-13.83% 的来源，逐笔配对实测 `trade_pairing_81d.json/csv`）**：
新旧 run 成交按 (信号日,代码,方向) 配对：**重叠仅 1 笔**（旧末次运行 35 笔 vs 新 14 笔）——价格域差异改变的不只是成交价，而是**整个决策集**（预算/整手/涨跌停/拒单全部重排）。NAV 差 +7.1pp 精确两段分解：
- **A 段（+20.13pp）= 04-01 同日 NAV 差**：旧 run 在 04-01 NAV 19,841 vs 新 run 15,815。构成：(a) 旧口径用 close_adj 成交+close_adj 估值，**持仓 mark 虚高**使 NAV 下跌被系统性延迟；(b) RAW 用 T+1 开盘成交，2026-03 上行段的高开缺口成为真实买入成本。两因同源：**adj 虚高的 NAV 让旧 run 03-24 时点尚未触发 -20% 线，RAW 诚实读数当周即锁**。
- **B 段（-13.04pp）= 路径截断的镜像**：旧 run 因 mark 虚高把 EXCEEDED 从 03-24 **推迟到 06-08**，多交易 3 个月后累计再亏 -2,607（04-01→末）。**风险状态机的锁死时点被价格口径污染所"软化"，结果不是少亏而是拖长持仓多亏 13pp**。
- 合并读法：**-13.83%（旧）= -20.93%（RAW 诚实账本）+ adj mark 虚高延迟锁死带来的 +7.1pp 幻觉**——其中没有一分钱是"实现 bug 压低了真实成绩"；相反，实现问题**抬高**了旧读数。方向性亏损主体仍是策略决策本身（601069/002207 双域 MAE 一致）+ 状态机放大。

**结构性发现（本报告的硬结论）**：
- **MERGED ≡ FV_ONLY（每列全等）**：双引擎多年窗 52 笔成交全部来自 FV——**LC 在资金竞争 + 风控闸门组合下多年零有效贡献**；LC 单独模式确有 18 笔（-21.4%），证明"LC 无测量通道"不是引擎不存在信号，而是**组合层的入场顺序/预算分配把它挤出**（与长窗 adj 域 long_backtest 发现一致，RAW 域复现）。
- **价格域影响符号不稳定**：多年窗 RAW(-20.80%) vs adj 域干净长跑(-21.76%)= **+0.96pp（修复后略好）**；81 日窗为 **-7.1pp（修复后更差）**。含义：raw-open 重建的价值在**账本正确性**（成交价可交易性/费用/涨跌停语义），**不在改变收益方向**；任何"修口径就能翻盘"的期待都不成立。
- 三模式全部以 EXCEEDED 锁死收场（MERGED/FV **2020-09-14** 即锁——RAW 成交口径下 NAV 恶化更快，比 adj 域长跑的 2020-10-30 提前约 6 周；LC 单独撑到 **2021-06-18** 才锁），空仓天数占窗 83–94%——阶段 3 状态机问题是**主导性实现问题**，独立于价格域存在；且 RAW 修正本身会**前移**锁死时点（口径与状态机的联动方向性证据）。

## 3. 账本质量声明

- RAW 三 run 均过 `ledger_selfcheck --raw`：C1 现金流水 / C2 NAV=cash+Σshares×raw close / C3 trades↔账本逐笔 / C4 股数守恒，**零失配**；账本行数=唯一 plan_hash 数（无 shadow_run 式污染）。
- adj 对照轨按 T0 锚归一（与 raw 同水平，轨差=窗内真实除权除息效应；81 日窗轨差 0 = 持仓段未遇除权，多年窗分解见 nav_hist_full.csv）。
- 股数不按 hfq 因子逐日换算（`adj_factor_check`：因子为滚动基准量，95.6% 行漂移≠除权事件）。
