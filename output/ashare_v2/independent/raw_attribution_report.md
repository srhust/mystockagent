## 1. 81 日窗（2026-03-02 → 2026-06-30）新旧对照

| 读数 | NAV末 | 相对20000 | 账本性质 |
|---|---|---|---|
| 旧 SHADOW（close_adj 成交+adj 估值） | 17,233.92 | **-13.83%** | **污染账本**（151行/81唯一hash，见 forensics） |
| 新 RAW（T+1 raw open 成交/raw close 估值） | 15,814.89 | **-20.93%** | 隔离新账本，selfcheck 四关全绿 |

**分解（-13.83% 的来源）**：
1. **价格域修正贡献 ≈ -7.1pp（方向：修复后更差）**——旧口径用 T+1 **收盘**成交，把"隔夜跳空买入成本"整体隐藏；RAW 用 T+1 **开盘**成交后，2026-03 上行趋势中的高开缺口变成了真实成本。这直接回答审查核心问题：**把价格口径修对，81 日读数不会回暖，反而恶化**——-13.83% 不是"实现 bug 压低了成绩"。
2. **风险状态机贡献 = 窗口内提前锁死**：RAW NAV 下跌更快，**03-24 即触 -20% → EXCEEDED 冻结新增**，04-01 全清仓后 NAV 恒平 15,814.89 直到窗口末（成交仅 14 笔，止于 04-01）。阶段 3 的 risk_lockout 在 81 日窗内同样实证（与多年窗 2020-11-11 起锁 1,436 天同构）。
3. **真实策略决策贡献**：锁前 14 笔的方向性亏损主体（601069/002207 两笔 LC 趋势延续入场即买在个股单边下行段，见 big_loss_attribution.json；adj/raw 双域 MAE 几乎一致 → **方向错误归决策不归口径**）。

**结构性发现（本报告的硬结论）**：
- **MERGED ≡ FV_ONLY（每列全等）**：双引擎多年窗 52 笔成交全部来自 FV——**LC 在资金竞争 + 风控闸门组合下多年零有效贡献**；LC 单独模式确有 18 笔（-21.4%），证明"LC 无测量通道"不是引擎不存在信号，而是**组合层的入场顺序/预算分配把它挤出**（与长窗 adj 域 long_backtest 发现一致，RAW 域复现）。
- **价格域影响符号不稳定**：多年窗 RAW(-20.80%) vs adj 域干净长跑(-21.76%)= **+0.96pp（修复后略好）**；81 日窗为 **-7.1pp（修复后更差）**。含义：raw-open 重建的价值在**账本正确性**（成交价可交易性/费用/涨跌停语义），**不在改变收益方向**；任何"修口径就能翻盘"的期待都不成立。
- 三模式全部以 EXCEEDED 锁死收场（2020-11 / 2020-11 / 2020-10 后永久冻结），空仓天数占窗 83–94%——阶段 3 状态机问题是**主导性实现问题**，独立于价格域存在。

## 3. 账本质量声明

- RAW 三 run 均过 `ledger_selfcheck --raw`：C1 现金流水 / C2 NAV=cash+Σshares×raw close / C3 trades↔账本逐笔 / C4 股数守恒，**零失配**；账本行数=唯一 plan_hash 数（无 shadow_run 式污染）。
- adj 对照轨按 T0 锚归一（与 raw 同水平，轨差=窗内真实除权除息效应；81 日窗轨差 0 = 持仓段未遇除权，多年窗分解见 nav_hist_full.csv）。
- 股数不按 hfq 因子逐日换算（`adj_factor_check`：因子为滚动基准量，95.6% 行漂移≠除权事件）。
