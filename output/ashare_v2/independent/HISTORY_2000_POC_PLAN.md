  1997-2000 制度期（30%涨跌停前身、5% ST、T+1 确立初期）信号是否退化（裁定§扩展）。

- 现有 `ashare_stock_pipeline.py`（16 元组域）与 `data/stocks/`（2020+ 快照池 251 文件）
  **保持原样**；扩展落**独立数据层**，验收前不与现役混读。

## 3. 独立数据层目录（工程隔离）

```
data/ashare_history_2000/
  daily_raw/            # 原始日线 csv（含 tradestatus/isST 列，不预复权）
  security_master/      # 证券主表（上市日/退市日/交易所/代码变更）
  corporate_actions/    # 事件级分红/送转/拆股/配股（包D apply_day_events 消费格式）
  industry_pit/         # 版本化行业归属（date-keyed；缺→UNKNOWN）
  manifest/             # 每次拉取的 sha256+行数+错误分布(fetch_guard.stats)快照
  QC/                   # POC 与验收报告（本文件§5）
```

纪律：新层自带 manifest（strict 模式哈希锚）；与 `data/stocks/` 冲突日 → 双侧登记 CONFLICT
记录，不自动覆盖；PIT 缺失一律 `UNKNOWN`，禁止前向填充归属。

## 4. POC 设计（先行小样本，验收通过才允许扩量）

**样本选择（12 只，分层）**：
- 1999 年前上市且仍存续 ×4（沪/深各2，含 600/000 段）
- 已退市/吸收合并 ×3（验证退市终止处理）
- 企业行动密集（多年送转+分红+配股）×3（对包D守恒链路端到端）
- ST 历史复杂 ×2（isST 时序）
- 长期停牌史 ×?（tradestatus 连续性；样本内至少 1）

**样本年份切片**：2000 / 2005 / 2008 / 2015 / 2020 / 2026 各抽全月，做逐切片：
1. 覆盖率（交易日数 vs 交易所日历）；
2. 与现有 sina 2020+ 面板**重叠段冲突率**（同券同日 close_raw 差异>0.5% 登记）；
3. tradestatus/isST 与面板行数一致性；
4. 企业事件在价格序列上的除权点核验（事件日期 vs 价格跳变 vs 理论除权价，
   容差 1%，超差样本列入不可信清单）。

**通道纪律**：全部调用经 `tools/fetch_guard.py`（cap 600/h、指数退避、熔断、错误分布统计）；
POC 总预算 ≤ 2,000 请求；任何熔断触发即停止当日批次并记录（不自激化限流——§5事故纪律）。

## 5. 验收判据（POC → 全量闸门）

POC 通过需同时满足（报告落 `QC/poc_report.json`）：
- A1 样本冲突率 < 1%（重叠段）；
- A2 退市券的退市日宇宙剔除正确（回放任意日成分无前视）；
- A3 企业行动密集样本在包D apply_day_events 后**守恒误差 < 0.01**且无 UNVERIFIED 残留；
- A4 行业 PIT 逐日 UNKNOWN 率量化并登记（不要求为 0，要求**已知**）；
- A5 fetch_guard.stats 显示零熔断死循环、错误分布可解释；
- A6 回放一致性：用 2000-2020 数据重跑 R0 **同一冻结参数**，输出只作状态/信号覆盖诊断，
  不作收益宣称（红线不变）。

任一不满足 → 停在 POC，扩量申请驳回。
