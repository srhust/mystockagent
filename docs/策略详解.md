# 三锚体系完整逻辑链

## 出发点：三个用户观察，三次数据验证

1. **"底部是相对的，很多健康的股回调也就50%"** → 固定 -50% 阈值在 30 行业验证有效（69事件 +27.9%/胜78%），但对牧原式成长股 12 年 0 信号 → 结论：阈值必须相对自身振幅
2. **"周期是否该以商品价格判断，股价反转往往先于商品"** → 196 事件检验：信号日商品距自身低点中位 +31%、82% 事件商品已反弹 >10% → 股价大幅领先商品，"等商品确认"必迟到（E4/X4 已证伪）
3. **"美光两年一周期"** → 干净数据下 MU 6 轮真实周期（2011/2015/2018/2020/2022/2025），固定 -50% 只抓 50%，漏掉的 2020/2022 均浅于阈值 → 自适应阈值 0.7×自身最深回撤

## 锚的设计

### 锚①相对回撤（入场结构）
- 距自身滚动高点回撤 ≥ T，T = max(30%, 0.7×近1250日最深回撤)
- 修复出场：dd 回升到 -25% 以上（资金效率优于 85 过热出场，贪心底盘 +15.2% vs +8.6%）
- 分批：T×0.8 首仓、T 加二仓、极值区三仓（=专户 30/35/35 的参数化）

### 锚②商品周期位置（防伪层）
- 深寒入场时若对应商品仍在自身 5 年区间高位（>60%），为成长污染型/需求错判型假信号
- 事件级：商品低位 +33.7% / 中位 +35.7% / 高位 +19.0%
- 在 dd 锚底盘上增量有限（dd 触发天然低位）——主要防纯温度假信号

### 锚③温度/广度（时点层）
- temp<12 扣扳机（股价领先商品 31% → 时点必须跟股价）
- 温度 = 60%×5年价格位置 + 25%×120日动量分位 + 15%×60日动量分位 + PB 分位

## 仓位管理（用户设计，数据验证）

| 试验 | 结论 |
|---|---|
| 组合级回撤加仓 | ✗ 无效 |
| 组合级回撤控制 | ✗ 无效 |
| 专户三档摊平 30/35/35 | ✓ 全面优于 40/30/30 |
| 大上涨中的深寒更肥 | ✓ +26.9% vs +20.9% |
| 85 出场 vs 75 | ✓ 非金融 85（专户）；贪心满仓模式下快速修复出场更优 |
| 6仓等权/同类≤2 | ✓ 组合底盘最优结构（轮动效率+相关风险控制） |

## 数据工程

- 前复权分段锚点漂移是最大坑：牧原假 +306%/5天、假 2018 -55% 均由此来
- 解法：baostock 单锚点全量重抓（247/247）+ 跨源核对（THS 30/30、新浪期货 12/12）
- 教训：复权不一致会让回测结论整体失真，数据审计先于策略

## 边界与未完成

- 捕获率 30%→80% 需分批建仓 + 组合级覆盖统计（多资产互为补充）
- 无成本线/库存/产能数据，行业亏损面等终极见底指标未接入
- 全市场（含退市股）无偏样本回测进行中（baostock，data/bs_all）
