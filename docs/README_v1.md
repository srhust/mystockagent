# 周期股量化交易系统 (Cyclical Stock Quant System)

一个聚焦于**周期股板块轮动**的量化分析系统。核心理念：周期股的行情由行业周期驱动，
**走周期的是整个板块而非个股**（存储、猪肉、航运、有色、煤炭……），因此系统以**板块/行业指数**
为分析单位，识别周期所处阶段，回答四个核心问题：

1. **周期什么时候启动？**
2. **周期什么时候见顶？**
3. **什么时候买入胜率最高？**
4. **什么时候买入收益最大？**

基于 30 个周期板块、2010-2026 年数据（约 10 万个交易日样本）的实证回答见「零、核心四问直答」
（`output/report.md`），一句话总结：**周期股是均值回归型资产——温度 0-10 的深寒区分批买入、
持有到温度 75+ 的过热区卖出，胜率 ~70%、年化 ~15%，完胜追涨杀跌**。

## 三、周期温度计（核心模型）

对每个板块计算 0-100 的**周期温度**，综合五个维度（缺失维度自动重归一化）：

| 维度 | 权重 | 计算方式 |
|------|------|---------|
| 价格位置 | 25% | 当前价在 5 年滚动高低区间的分位 |
| 动量 | 25% | MA20/MA60/MA200 排列 + 20/60/120 日收益 |
| 估值分位 | 25% | 板块 PB 中位数的历史分位（周期股用 PB 比 PE 可靠：底部 EPS 亏损→PE 失效）|
| 板块广度 | 15% | 成分股站上 MA200 的比例、创 250 日新高比例 |
| 量能 | 10% | 成交额相对 1 年均值的放大程度 |

温度分区：
- `0-10` 深寒区（**实证最优买点**：120日胜率 70.7%，250日 74.6%）
- `10-20` 冰点区（次优买点）
- `20-40` 探底区（**最差买点**——下落刀，胜率仅 47%）
- `40-60` 启动/回暖区
- `60-80` 扩张区（趋势持有，120日 +6.7%~+10.8%）
- `80-90` 过热警戒区（动量末段，120日 +16% 但 250 日衰减）
- `90-100+` 见顶逃命区（120日胜率 43%，>100 时平均收益 -5.5%）

### 周期阶段状态机

```
下行(Decline) ─▶ 底部(Bottom) ─▶ 启动(Recovery) ─▶ 扩张(Expansion) ─▶ 见顶(Topping) ─┐
    ▲                                                                                │
    └────────────────────────────────────────────────────────────────────────────────┘
```

转移规则（右侧确认 + 左侧预警 + 迟滞防抖动）：
- **→底部**：温度 < 20 且 20日动量企稳（> -6%），或温度 < 35 且动量 > -3%（防过早抄底）
- **底部→启动**：温度上穿 40 且价格站上 MA200 且 MA20>MA60 且 mom20>0
- **启动→扩张**：温度 > 55 且 MA 多头排列
- **扩张→见顶**：温度 > 80 且 (死叉 或 高点回撤>15% 或 PB 分位>85%)
- **任何→下行**：MA20 下穿 MA60 且温度 < 50
- **见顶→扩张（回补）**：温度回落 < 55 且重新满足扩张条件（迟滞，防反复横跳）

## 四、量化因子库与实证有效性

6 个因子在 30 板块 × 20/60 日时序秩 IC（跨板块平均）：

| 因子 | IC(60d) | 含义 |
|------|---------|------|
| price_pos 价格位置 | **-0.57** | 位置越高未来收益越差 |
| temp 周期温度 | -0.52 | 越热未来越差 |
| mom60 动量 | -0.45 | 动量为**反向**指标 |
| breadth 广度 | -0.40 | 广度极值反向 |
| rs60 相对强度 | -0.35 | 相对强度反向 |
| pb_pct PB分位 | -0.31 | 低 PB=周期底=未来收益高 |

**全部为负** → 周期股板块指数是强均值回归型资产，这与成长股/大盘指数的动量效应相反。
策略含义：左侧逆向（买深寒）> 右侧追涨。

## 五、策略（4 种模式，回测 2012-2026，T+1 收盘成交，单边成本 0.15%）

| 策略 | 规则 | 年化 | 胜率 | 夏普 | 回撤 |
|------|------|------|------|------|------|
| **深寒左侧(推荐)** | 温度<12 买入，温度>75 卖出，不止损 | **14.6%** | **91%** | **0.74** | -41% |
| 深寒左侧+25%止损 | 同上+移动止损 | 13.7% | 63% | 0.72 | -38% |
| 混合 | 深寒(15)累积 或 右侧启动买入；>78 过热封锁 | 11.6% | 88% | 0.59 | -46% |
| 右侧确认 | 阶段∈{启动,扩张}持有，见顶/下行卖出 | 5.2% | 40% | 0.34 | -58% |
| （基准）等权持有全部 | — | 12.2% | — | 0.61 | -50% |
| （基准）沪深300 | — | 4.4% | — | 0.31 | -47% |

关键实证发现：
- **移动止损对深寒仓有害**（胜率 91%→63%）：周期底部的噪声会把底仓震出去
- 深寒策略平均持有 371 天 ≈ 一轮完整上行周期（ZigZag 测得平均 367 天/+99%）
- 右侧确认策略反而跑输等权持有——「确认成本」吞掉了鱼头

### 组合构建
- 等权持有最多 4 个（深寒模式 6 个）满足条件的板块
- 同一周期类别（如资源类）最多 2 个板块，分散单周期风险
- 买入候选按信号强度（动量+相对强度+温度斜率）排序

## 七、快速开始

```bash
# 日常使用（三步走）
python scripts/fetch_data.py    # ① 增量更新数据（首次约30分钟, 日常约5分钟）
python scripts/status.py        # ② 秒级查看当前周期状态 + 深寒/过热名单 + 近期动向（日常最常用）
python main.py                  # ③ 全流程深度分析: 胜率统计 + 回测 + 完整报告（约3分钟）

# 盘中监控（交易时段内）
python scripts/intraday.py              # 一次性扫描30板块盘中温度（约2秒, 单次联网）
python scripts/intraday.py --watch      # 循环监控（默认300秒/轮, Ctrl+C 退出）
python scripts/intraday.py --watch --interval 60 --vol-table   # 1分钟一轮 + 量纲校验明细
# 盘中温度 = 同花顺行业实时涨跌幅换算盘中点位 + 日内量能折算 → 拼接缓存序列重算
# 自动防护: 休市/盘前显示收盘态(防重复计入), 量纲校验不过自动回退, 温度越界报错

# 常用选项
python main.py --no-fetch                  # 只用本地缓存（离线/网络故障时, 哪怕缓存过期也不联网）
python main.py --sectors 养殖,半导体,煤炭   # 只分析指定板块
python main.py --mode cold                 # 只回测指定策略(right/dual/cold/hybrid/...)
python scripts/status.py --refresh         # 更新数据 + 查看状态（①+②一步完成）
python scripts/status.py --rebuild         # 强制重建富化缓存（数据更新后）
python scripts/test_engine.py              # 合成数据引擎自检（无网络依赖）
```

## 九、主要实证结论（详见 output/report.md）

1. **买点**：温度 0-10 深寒区分批买入 → 120 日胜率 70.7%、250 日 74.6%；分期检验
   （2019 前 67% / 2019 后 84%）与 6 因子全负 IC 互相印证
2. **卖点**：温度 > 90 + PB 分位 > 85% + 技术走坏；温度 100+ 区 120 日平均收益 -5.5%
3. **周期长度**：平均上行 367 天 / +99%，平均下行 ~300 天 / -35%（ZigZag 25% 反摆）
4. **商品联动**：商品期货与板块股价**同步**（月频相关 0.1-0.6），无稳定的月度级领先关系——
   商品价格本身不是时点工具，温度/估值框架更有效
5. **右侧确认的代价**：启动信号（温度上穿 40+站上 MA200）后 120 日胜率仅 53.7%（≈基准），
   追确认会错过 V 型反转的鱼头

## 十、已知局限

- PB 历史仅约 10 年（百度源），2017 年前温度自动降权重归一化
- 板块指数为同花顺行业指数（流通市值加权），广度用等权代表股，两者有差异
- 回测未计入涨跌停无法成交、停牌等微观结构约束（信号次日收盘价成交已部分保守化）
- 深寒策略最大回撤 -41%：深寒可以更寒（周期底后还有周期底），仓位管理与分批建仓必要
